# 📑 Contents Breakdown

---

## 🎯 1. Lab Experiments

### 📊 Supervised Learning
Focuses on fundamental classification and regression algorithms, including model comparative analysis:

* **Linear Regression:** Continuous variable predictions using datasets like `insurance.csv` and `weatherHistory.csv`.
* **Logistic Regression:** Binary classification modeling.
* **Decision Trees:** Tree-based predictive modeling.
* **Naive Bayes:** Probabilistic classification models.
* **Comparative Studies:**
  * Linear Regression vs. Decision Trees
  * Naive Bayes vs. Logistic Regression

---

### 🔍 Unsupervised Learning
Explores clustering techniques and pattern recognition on unlabelled data:

* **K-Means Clustering:** Centroid-based customer segmentation using `store_customers.csv`.
* **DBSCAN:** Density-based spatial clustering for complex data structures.

---

## 📝 2. Coursework Assignments

Domain-specific machine learning applications and problem-solving assignments:

* **Healthcare Analytics:** Patient outcome analysis and Random Forest model implementations.
* **Industrial Automation:** Predictive modeling on machine operational data (`machine_data.csv`).
* **Smart Cities:** Urban intelligence analysis leveraging traffic datasets (`traffic_data.csv`).
